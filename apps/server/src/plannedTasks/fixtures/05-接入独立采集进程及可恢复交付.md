## 交付行为

工作台通过命名管道控制独立设备进程，接收持久化页文件及结构化状态，断开后可以查询和恢复交付。

本项按用户可观察的完整行为验收，依赖未完成时不得领取；需要实现时还须取得编码授权。

## 前置条件

无额外外部资料硬前置；按依赖任务的已验收输出开展，使用明确标记的可控夹具，不声称真实设备或外部联调通过。

## 验收条件

- [ ] 在独立副本复用采集实现，驱动位数与工作台隔离，不修改原工程，不跨进程传运行时图像对象。
- [ ] 建立任务控制、状态、页落盘和终态事件及游标重放；重复开始或重连不重复进纸。
- [ ] 停止请求、失败、未知终态和正常结束分开，进程超时不伪造最后一页完整。
- [ ] 分类环境不可用仍可启动采集和本地保存；设备故障不会令工作台丢失已存页。
- [ ] 用可控设备边界注入断连、迟到事件和进程崩溃；真实设备结果由06单独验收。

## 验证证据

记录执行版本、输入、环境、步骤、预期/实际、日志及通过/失败/未测项。资料缺失不能写作通过，模拟与真实验证分列。未实际执行，本文件只定义后续工作。

## 边界

不修改原工程，不引入未经确认的业务范围或重大技术替换。任务状态不授权编码、提交、推送或部署；当前仅创建任务。
